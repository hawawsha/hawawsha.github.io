سياسة الخصوصية - متجر Souq Pi

آخر تحديث: يوليو 2026

1. البيانات التي نجمعها

عند استخدامك لتطبيق Souq Pi عبر Pi Browser، نقوم بجمع معرّف المستخدم (UID) واسم المستخدم المرتبطين بحساب Pi Network الخاص بك، بالإضافة إلى بيانات الطلبات والمدفوعات التي تنفذها داخل المتجر.

2. كيفية استخدام البيانات

تُستخدم هذه البيانات حصراً لإتمام عمليات الشراء، ومعالجة المدفوعات عبر شبكة Pi Network، وإرسال إشعارات متعلقة بحالة طلباتك.

3. مشاركة البيانات

لا نقوم ببيع أو مشاركة بياناتك مع أي طرف ثالث، باستثناء ما يلزم لإتمام عملية الدفع عبر Pi Network نفسها.

4. تخزين البيانات

تُخزَّن بيانات الطلبات والمدفوعات في قاعدة بيانات آمنة (MongoDB) ولا تُحفظ أي معلومات مالية حساسة خارج شبكة Pi Network نفسها.

5. التواصل معنا

لأي استفسار بخصوص هذه السياسة، يمكنكم التواصل معنا عبر تطبيق Souq Pi مباشرة.
