شروط الخدمة - متجر Souq Pi

آخر تحديث: يوليو 2026

1. قبول الشروط

باستخدامك لتطبيق Souq Pi عبر Pi Browser، فإنك توافق على الالتزام بهذه الشروط والأحكام.

2. طبيعة الخدمة

Souq Pi هو متجر إلكتروني يتيح شراء وبيع المنتجات باستخدام عملة Pi عبر شبكة Pi Network، ويعمل حالياً على بيئة الاختبار (Testnet).

3. المدفوعات

تتم جميع المدفوعات عبر Pi SDK الرسمي، ويخضع تأكيد الدفع وإتمامه لموافقة شبكة Pi Network. لا يتحمل المتجر مسؤولية أي تأخير أو خلل ناتج عن شبكة Pi Network نفسها.

4. المسؤوليات

يلتزم المستخدم بتقديم بيانات صحيحة عند إتمام أي عملية شراء، ويتحمل مسؤولية أي معاملة يقوم بتأكيدها بنفسه عبر تطبيق Pi Network.

5. التعديلات

نحتفظ بالحق في تعديل هذه الشروط في أي وقت، وسيُعلن عن أي تغييرات جوهرية عبر التطبيق.

6. التواصل

لأي استفسار بخصوص هذه الشروط، يمكنكم التواصل معنا عبر تطبيق Souq Pi مباشرة.
